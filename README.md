# Vaali Stones Website

Architectural stone sourcing platform for **Vaali Stones** — live at **https://stones.vaaliadvisory.com**

Professional material selection and specifications interface connecting designers, architects, and builders with premium natural stone options including granite, marble, limestone, and sandstone.

## Stack

- React 19 + Vite 6
- React Router 7
- Tailwind CSS 3 (same navy/gold design system as Vaali Foods)
- Lucide icons
- GitHub Pages deploy via Actions

## Development

```bash
npm install
npm run dev
```

## Deploy

Push to `main` on GitHub with Pages enabled, or:

```bash
npm run deploy
```

Set custom domain **stones.vaaliadvisory.com** in repository Pages settings (CNAME included in `public/CNAME`).

## Pages

| Route | Content |
|-------|---------|
| `/` | Home — hero, about intro, products, testimonial, global reach |
| `/about` | Company story, CEO message, quality & CSR |
| `/products` | Granite, marble, limestone, sandstone |
| `/facilities` | Manufacturing, delivery, packaging, QC |
| `/artifacts` | Monuments & stone articles |
| `/contact` | Enquiry form, office details, FAQ |
